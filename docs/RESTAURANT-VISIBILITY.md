# ซ่อนและแสดงร้านในแอป

ในหน้า Admin เปิดร้านแล้วเลือก **ซ่อนร้านจากแอป** จากนั้นกด **บันทึกทั้งหมด**
ร้านยังคงอยู่ในฐานข้อมูลพร้อมรูปและประวัติ เปิดกลับได้โดยเอาเครื่องหมายออกแล้วบันทึก
ใช้ตัวกรอง **ซ่อนจากแอป** เพื่อค้นหาร้านที่ซ่อนอยู่

ร้านที่ซ่อนจะไม่อยู่ในการค้นหา หมวดที่มีเฉพาะร้านซ่อน หรือชุดร้านที่สร้างใหม่
ชุดร้านของห้องที่เริ่มเล่นแล้ว รายการถูกใจ ผลจับคู่ และประวัติยังอ่านได้เหมือนเดิม
ข้อมูลที่โหลดค้างอยู่ในมือถือจะไม่ถูกดึงออกทันที ต้องโหลดรายการใหม่

ทุกครั้งที่เปลี่ยนสถานะจะมีประวัติผู้แก้และค่าก่อน/หลัง ใช้ version ป้องกันการเขียนทับ
แท็บ Admin รุ่นเก่าที่ไม่ได้ส่งสถานะซ่อนจะคงสถานะเดิม ไม่เปิดร้านกลับโดยไม่ตั้งใจ
การแก้สถานะทำให้ร้านเป็นข้อมูล curated ถาวร ไม่ถูก seed/OSM refresh เปิดกลับเอง

หากใช้ Google live fallback ระบบตัดผลที่ชื่อเหมือนร้านซ่อนและอยู่ห่างไม่เกิน 100 เมตร
ด้วยกฎเดียวกับการตัดร้านซ้ำเดิม ชื่อที่ต่างกันหรือพิกัดคลาดเคลื่อนอาจยังต้องตรวจซ้ำ
ไม่มีการลบข้อมูลจาก Google และไม่มีการสร้างคำขอ Google เพิ่มเพื่อทำการซ่อน

ต้อง deploy backend/ไฟล์เว็บรุ่นเดียวกันพร้อม migration `0008` ซึ่งเพิ่ม
`restaurants.is_hidden` โดยร้านเดิมทั้งหมดเริ่มเป็นแสดงในแอป
ไม่ต้องสร้าง Android AAB ใหม่เพื่อใช้การซ่อนร้านจาก Backend
การย้อนเฉพาะโค้ดรุ่นก่อนฟีเจอร์นี้จะไม่กรองสถานะซ่อน ต้องประเมินก่อน rollback
และไม่ถอย migration อัตโนมัติบน production
